# Askbox — анонимные вопросы для TikTok

Блогер регистрируется по логину и паролю, получает ссылку и QR-код. Подписчики задают вопросы анонимно и без регистрации, а ответ читают по своей секретной ссылке. Блогер может одной кнопкой сделать картинку 9:16 с вопросом и ответом для TikTok Story.

Всё работает на бесплатных тарифах: **Supabase** (база данных) + **Vercel** (сайт).

---

## Запуск за ~15 минут (программировать не нужно)

Понадобятся три бесплатных аккаунта: Supabase, GitHub и Vercel.

### Шаг 1. База данных (Supabase)

1. Зарегистрируйтесь на **supabase.com** → **New project**.
2. Придумайте и **сохраните пароль базы** (Database Password). Регион: Frankfurt (eu-central-1) или ближайший к аудитории.
3. Когда проект создастся, откройте слева **SQL Editor** → **New query**.
4. Откройте из этой папки файл `db/schema.sql`, скопируйте всё содержимое, вставьте в редактор и нажмите **Run**. Должно появиться «Success».
5. Нажмите кнопку **Connect** вверху страницы проекта → вкладка **Connection string** → выберите **Transaction pooler** (порт **6543**). Скопируйте строку и замените в ней `[YOUR-PASSWORD]` на пароль из пункта 2. Это ваш `DATABASE_URL`.

### Шаг 2. Код на GitHub

1. Зарегистрируйтесь на **github.com** → справа вверху **+** → **New repository**.
2. Название, например, `askbox`, выберите **Private** → **Create repository**.
3. На странице репозитория нажмите ссылку **uploading an existing file**.
4. Перетащите в окно **всё содержимое** распакованной папки (файлы и папки `app`, `components`, `db`, `lib` и т. д., а не саму папку целиком) → **Commit changes**.

### Шаг 3. Сайт (Vercel)

1. Зарегистрируйтесь на **vercel.com** через GitHub (тариф Hobby — бесплатный).
2. **Add New… → Project** → выберите репозиторий `askbox` → **Import**.
3. Разверните **Environment Variables** и добавьте две переменные:
   - `DATABASE_URL` — строка из шага 1.5;
   - `APP_SECRET` — длинная случайная строка, минимум 32 символа (можно взять готовую из сообщения в чате).
4. Нажмите **Deploy** и подождите 1–2 минуты. Vercel покажет адрес сайта вида `askbox-xxx.vercel.app`.

### Шаг 4. Проверка

1. Откройте сайт → **Создать страницу** → сохраните код восстановления.
2. Откройте свою ссылку `адрес-сайта/ваш_логин` на **другом телефоне** (или в режиме инкогнито) и задайте вопрос.
3. В кабинете ответьте → **Сделать карточку для сторис** → **Поделиться в TikTok Story**.
4. На втором телефоне откройте секретную ссылку — там должен быть ответ.

Если что-то не работает: Vercel → проект → **Logs**. Скопируйте текст ошибки и пришлите его в чат.

## Дополнительно

- **Своё имя сервиса.** Добавьте в Vercel переменную `NEXT_PUBLIC_SITE_NAME` (например, `Спроси меня`) и сделайте Redeploy.
- **Свой домен.** Vercel → Settings → Domains. После подключения задайте `NEXT_PUBLIC_SITE_URL=https://ваш-домен` — QR-коды будут вести на него.
- **Капча от спама** (бесплатно): dash.cloudflare.com → Turnstile → Add site. Ключи пропишите в `NEXT_PUBLIC_TURNSTILE_SITE_KEY` и `TURNSTILE_SECRET_KEY`.
- **Бесплатный Supabase «засыпает»** после 7 дней без посещений. Тогда зайдите в панель Supabase и нажмите Restore. На живом сервисе такого не происходит.
- **Бесплатный тариф Vercel рассчитан на некоммерческие проекты.** Если появится реклама или платные функции, нужен тариф Pro или другой хостинг.

## Как устроена безопасность

- Пароли и коды восстановления хранятся только в виде хешей scrypt. Сессии — случайный токен в httpOnly-cookie, в базе лежит только его SHA-256.
- Данные лежат в отдельной схеме `app`, закрытой от публичного API Supabase. На всех таблицах включён RLS без разрешающих правил. Доступ есть только у сервера сайта.
- Каждый запрос блогера проверяет владельца прямо в SQL (`creator_user_id = текущий пользователь`). Чужой вопрос нельзя увидеть, изменить, удалить или сделать из него карточку, даже зная его ID. ID вопросов — случайные UUID.
- Секретная ссылка: 256-битный случайный токен, в базе только SHA-256. Токен стоит после `#` в адресе, поэтому браузер не отправляет его на сервер и он не попадает в логи. Страница передаёт токен в теле POST-запроса.
- Ограничение частоты запросов на регистрацию, вход, восстановление, вопросы и чтение ответов. IP хранится только в виде необратимого хеша и удаляется примерно через 2 дня. С вопросом IP не связан.
- Защита от CSRF (проверка Origin), лимиты длины, очистка текста. React экранирует весь пользовательский текст.
- Фильтр мата и угроз (блогер может его выключить), удаление вопросов и аккаунта.

## Ограничения первой версии

- Отправитель не получает уведомлений: ответ нужно смотреть по секретной ссылке или в разделе «Мои вопросы» на том же устройстве.
- Сайт не может гарантированно открыть сразу редактор TikTok Stories. Кнопка открывает системное меню «Поделиться» (там есть TikTok), а если телефон его не поддерживает — скачивает картинку. Это нужно проверить на реальных iPhone и Android.

## Для разработчика

```bash
npm install
cp .env.example .env.local   # заполнить DATABASE_URL и APP_SECRET
psql "$DATABASE_URL" -f db/schema.sql
npm run dev
```

Стек: Next.js 15 (App Router), PostgreSQL через `postgres`, `next/og` для карточек, `qrcode`, шрифт Manrope.
